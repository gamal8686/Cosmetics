

# Cosmetics

A Flutter project for learning and building a cosmetics-related app.

## Getting Started

This project is a starting point for a Flutter application.  
It demonstrates basic Flutter setup, navigation, and state management.

### Prerequisites

Before running this project, make sure you have:

- Flutter installed on your machine: [Flutter installation guide](https://flutter.dev/docs/get-started/install)
- An IDE such as Visual Studio Code or Android Studio
- A connected device or emulator for testing

### Project Structure
 
### Features

- Home screen displaying cosmetics products
- Navigation between screens
- State management using setState (or alternative methods)
- Placeholder for integrating backend or API
- Basic responsive UI for mobile devices

### Dependencies

Key dependencies used in this project:

- `flutter_svg` → For rendering SVG images
- `pin_code_fields` → For PIN input fields
- `lottie` → For animations
- `clipboard` → For copying to clipboard
- `flutter_screenutil` → For responsive UI
- `animate_do` → For animation effects
- `dio` → For network requests / APIs
- `google_maps_flutter` → For Google Maps integration
- `shared_preferences` → For local storage
- `carousel_slider` → For image sliders
- `shimmer` → For loading placeholders
- `flutter_bloc` → For state management
